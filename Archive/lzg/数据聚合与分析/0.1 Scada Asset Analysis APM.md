**工业软件最核心的竞争区：SCADA → APM（资产性能管理）→ 业务闭环**。
---

# 🧠 一句话核心结论

> 全球主流 SCADA 厂商 **几乎全部已经往上延伸到“资产管理 + 分析 + 预测维护”层**
> 但实现路径分两类：
>
> * 🟢 **AVEVA / GE / Honeywell：强“统一平台”**
> * 🔵 **Siemens / ABB / Rockwell：中国厂商：偏“组合式架构”**

---

# 一、先建立整体架构（最关键）

```text
SCADA（数据采集）
   ↓
Historian / Data Platform
   ↓
Asset Model（资产模型）
   ↓
Analytics（规则/AI/模型）
   ↓
APM（资产性能管理）
   ↓
业务闭环（告警 / 工单 / 运维 / 预测维护）
```

👉 你问的本质就是：

> **谁在 SCADA 之上做到了“后面这 4 层”**

```text
SCADA + IoT + AI + App
```

* 分层解耦

```text
SCADA + MES + 报表 + 项目定制
```

👉 特点：
