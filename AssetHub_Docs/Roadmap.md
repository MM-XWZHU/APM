### 🗺️ 智汇资产平台 (Smart Asset Hub) Roadmap
该分阶段的软件开发Roadmap，核心策略是：**“内核重构、接口解耦、场景驱动”**。即先构建稳固的资产数据底座（内核），再通过标准接口连接上下层（解耦），最后以用户业务价值为导向开发具体应用（场景），并利用EMS项目作为首个“试验田”验证架构的扩展性。

#### 📅 阶段一：基石构建与核心重构 (Foundation & Core Refactoring)
**目标**：完成从“项目定制代码”到“通用资产底座”的蜕变，建立标准化的资产数据模型，实现与WAGO SCADA的基础对接。

**2. SCADA 集成适配层 (Data Integration)**
核心任务是构建**双向模型驱动的深度同步机制**，打破资产平台与 WAGO SCADA 之间的数据孤岛。
*   **模型与实例的双向映射**：建立“定义即生成”的自动化流程。当在资产平台新建**设备类型**（含参数模板）时，自动在 SCADA 端创建对应的**类模型/模板**；当新建**设备实例**时，自动在 SCADA 端实例化对应的**模型实例**。类似地，资产端的修改或删除操作将实时触发 SCADA 端模型与实例的更新或移除，确保两端元数据严格一致。
       - 采用 **“事件驱动的即时同步 **(Event-Driven Real-time Sync) 策略。鉴于设备模型变更（如新增测点、修改量程）直接影响数据采集的正确性，延迟同步可能导致数据丢失或采集错误。因此，建议资产平台每发生一条关键记录变化（增/删/改），立即通过 API 回调触发 SCADA 端的对应操作，确保“配置生效零时差”。仅在大规模初始化迁移场景下，才启用批量下发模式。
*   **配置态与运行态分离**：在**配置态**，通过同步机制维护 SCADA 的对象结构；在**运行态**，考虑两种可行方式：
       - 资产平台仅订阅 SCADA 的报警。实时数据由页面端直接订阅SCADA服务端的推送
       - 资产平台(建议按需)订阅数据点位变化，用于资产平台内置数据(库)更新。考虑到资产平台建立大量设备和数据点位时，全部订阅SCADA点位会造成两个应用系统的无效数据中转，不建议全量订阅数据更新。

#### 📅 阶段二：能力开放与EMS试点验证 (Integration & Pilot Validation)
**目标**：通过重构独立的EMS平台，验证资产底座的适配能力和接口扩展性，实现“最小修改，最大复用”。

*   **1. 资产平台能力接口化 (Platform as a Service)**
    构建标准化的北向业务API，提供资产查询、工单创建、报警订阅等通用接口供上层系统调用；建立基于消息队列的事件总线 (Event Bus)，实现资产状态变更或报警时的主动推送机制，解耦上下层系统。

*   **2. EMS 平台重构试点 (The Pilot Project)**
    利用独立的EMS平台作为“试验田”，剥离其原有的设备管理和硬编码逻辑，全面替换为调用“智汇资产平台”的API；在此过程中验证底座对能源管理特有需求（如计量点位映射、能效计算）的适配性，并反向优化底座模型。

> **💡 架构关键点**：利用EMS项目作为“白盒测试”，重点考察底座的**字段扩展能力**（不同行业资产属性差异大）。

#### 📅 阶段三：智能增强与业务价值呈现 (Intelligence & Value Realization)
**目标**：引入AI能力，从“被动记录”转向“主动预测”，并以用户视角的设备地图、健康画像等功能释放数据价值。

*   **1. 用户视角业务应用 (User-Centric Apps)**
    构建“宏观全景监控 + 微观深度执行”的一体化业务门户。
    *   **全景监控驾驶舱 (Unified Monitoring Dashboard)**
        构建**“逻辑拓扑为主、地理空间为辅”**的通用型监控门户，确保在无厂区平面图场景下依然能提供核心运维态势感知。
        *   **双模视图自适应**：
            *   **默认模式（逻辑拓扑视图）**：不依赖物理图纸，直接基于**设备分类树**或**工艺段拓扑**展示全局态势。用户可按设备类型（如泵类、风机类）、所属车间或工艺段层层钻取，直观查看各类别的**报警分布统计**、**工单积压数量**及**健康度聚合指标**。此模式标准化程度高，适用于所有客户场景，实施零门槛。
            *   **增强模式（地理空间视图）**：若客户具备 GIS 或厂区平面图，可一键切换至地图模式，将上述统计指标叠加至物理位置，实现“图上作战”。
        *   **时空数据融合分析**：
            *   **实时与历史并重**：驾驶舱不仅汇聚**实时运行数据**（当前状态、即时报警），更内置**历史趋势分析组件**。支持用户在同一界面下对比“今日 vs 昨日”、“本周 vs 上周”的关键指标变化，或查看特定设备类型的**长周期故障趋势曲线**。
            *   **价值**：从单纯的“实时监控”升级为“趋势洞察”，帮助管理人员识别周期性故障规律，确保系统核心功能的**稳定性**与**快速交付能力**。

    *   **设备 360°全景档案 (Micro View)**：打造以单台设备为核心的全生命周期视图。一键聚合展示该设备的**静态档案**（型号、参数）、**动态轨迹**（实时趋势、健康评分演变）及**历史足迹**（报警史、维修记录、备件消耗）。
    
*   **2. 资产健康画像 (Health Scoring)**
    融合实时工况数据、历史维修记录及巡检结果，利用算法为每台核心资产生成 0-100 的实时健康评分；结合退化曲线评估资产剩余使用寿命 (RUL)，为管理层提供“继续维护”或“投资更换”的决策依据。

*   **3. 高级异常监测 (AI Monitoring)**
    集成无监督学习算法进行AI异常检测，捕捉传感器数据中的微小偏差，在故障成型前发出早期预警；基于标准化故障体系，利用历史数据训练模型，自动推荐故障可能的原因和处置措施。
